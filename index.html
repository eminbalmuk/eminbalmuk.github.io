Giyiver

Co-founder & CTO

Turkish clothing-swap marketplace (barter, donation, points) live at giyiverr.com. Backed by investment received through Shell ILERIDE. We are a team of 7, and I am responsible for the entire technical side of the project: web, mobile, backend, infrastructure, AI, security and testing.

  • AI listing autofill: a vision-language model (NVIDIA NIM, Nemotron 3.5 Super VL) turns uploaded photos into title, category, colour, condition and description; images are downscaled client-side and sent as validated base64, so nothing is stored before publishing.
  • Model selection and hedged inference: benchmarked candidate VLMs on real listing photos, dropped unreliable ones, disabled reasoning mode for 2-10 s typical latency, and added a fallback model that races the primary after 12 s (first valid answer wins, the loser is cancelled).
  • Multimodal moderation: one VLM call checks all photos and text of a listing (real clothing, same item in every photo, consistent description); free text also passes a local profanity filter and an AI check, built to fail open and backed by database triggers.
  • Verified-image tokens: HMAC-signed, user-bound tokens carry SHA-256 digests of the analysed images; at publish time the server re-hashes the uploaded files and skips the second VLM call only if every digest matches, saving latency and cost without trusting the client.
  • Platform: Next.js on Cloudflare Pages with edge functions, Supabase Postgres with row-level security (57 migrations) and server-side points escrow, an Expo/React Native app, crawler-only rendering for SEO, and 570+ automated tests including SQL tests on a real Postgres engine.

Orion Innovation

AI Engineering Intern

Building LLM, retrieval and speech systems across three projects: SOSIS (Software product line Optimization for Safety-/mission-critical Industrial Systems, ITEA 4), an AI-driven test management platform; GENIUS (Generative AI for the Software Development Life Cycle), LLM-based requirement extraction; and CLEAR (Call Listener Emergency Audio Recognition), real-time audio intelligence for emergency call centers.

  • SOSIS: Designed a hybrid retrieval pipeline (dense embeddings + BM25, reciprocal rank fusion, GraphRAG) with optional listwise LLM reranking that links requirements, tests and source code automatically.
  • Benchmarked 20+ LLMs across 5 providers and 10+ embedding models on hand-labeled gold sets with paired bootstrap confidence intervals, reaching MRR 0.71 (requirement-to-test) and Hit@5 97.5% (test-to-code); wrote the study up as a research paper.
  • Built an LLM pipeline that turns requirements into runnable Playwright tests, grounded with retrieved code, a graph-based page selector (page@3 63% → 90%) and a headless-browser probe of the live UI, plus checks that feed the model its own mistakes back before the first run.
  • Built LLM agents that adapt tests to a product variant, run them, repair failures from the run report and review the outcome (LLM-as-a-judge); mapped requirements to variants with a hybrid embedding scorer (F1 0.74).
  • Unified OpenRouter, NVIDIA NIM, Groq and Google AI Studio behind one client with provider routing, price caps and a token-per-minute scheduler.
  • GENIUS: Optimized the multi-stage LLM requirement-extraction pipeline by batching zone classification, query expansion and rationale generation: LLM requests per document fell from 95 to 9 (zone classification 107 s → 3 s, now well inside Groq's rate limit), and controlling reasoning effort on GLM 5.3 Flash halved token use (336K → 165K).
  • Evaluated the extracted requirements against a hand-written ground truth (12 of 18 items matched fully, 6 partially, none missed), and integrated GENIUS into SOSIS so that its EARS/LESS requirements and labels (ISO 25010 quality dimension, actor, classification) feed test generation and variant mapping.
  • CLEAR: Built a streaming pipeline that runs speech recognition (Qwen3-ASR with LoRA), speaker diarization, speech emotion, stress and audio-event models on live 911/112 calls, fully on-premise on CPU.
  • Trained calibrated accent classifiers on Whisper encoder features and combined emotion and stress signals for distress detection (AUROC 0.87 vs 0.71 for stress alone).
  • Evaluated models on public benchmarks: 6.3% WER on clean speech, 86% emotion accuracy (vs 41% for the earlier approach), first words appear on screen in about 2 s.
